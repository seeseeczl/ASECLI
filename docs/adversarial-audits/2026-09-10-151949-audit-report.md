## Findings 详情

### [P1] AA-COR-001 — 在语义转换前拒绝悬空连线 — `src/asecli/sg_export/decoder.py:76-80`

- 证据等级：已验证。
- 触发条件：在有效 ASE 图中增加 `WireConnection;999;0;10;0`，保留原有 Master 连线。
- 错误行为：`asecli validate` 返回 `DANGLING_WIRE` 和非零退出码；`export-sg` 却将不存在的目标节点直接 `continue`，最终退出码为 0，`source_parse` 和后续全部门禁均标记 `passed`。
- 影响：损坏的 ASE 图可被声称转换成功，且连线被静默删除，直接违反 fail-closed。
- 最小修复方向：在 `build_candidate` 开头复用现有结构校验，并将所有 error 级 issue 写入报告；至少对 `destination is None` 显式产生阻断诊断。
- 关联优化任务：AA-OPT-001。

### [P1] AA-COR-002 — 对未认证 Master 设置失败关闭 — `src/asecli/sg_export/decoder.py:146-165`

- 证据等级：已验证。
- 触发条件：将真实 URP Unlit Master 的 `Cast Shadows` 序列化值从 `1` 改为 `0`。
- 错误行为：两份源图生成完全相同的 `target`；同时含该变异、悬空连线和外部属性的样本仍通过真实 SGCLI create 预览。
- 影响：Cast Shadows、Receive Shadows、LOD CrossFade、深度等效果设置可回落到 SG 默认值，即使编译通过也可能产生不同渲染结果。
- 最小修复方向：建立已认证 Master 设置白名单，逐项输出到 Target；其余存在且非认证默认的设置立即阻断。
- 关联优化任务：AA-OPT-002。

### [P1] AA-DATA-003 — 对图外 ShaderLab 属性建立完整性对账 — `src/asecli/sg_export/decoder.py:52-105`

- 证据等级：已验证。
- 触发条件：在 ShaderLab `Properties` 中增加 `_ExternalGain`，不增加对应 ASE Property 节点。
- 错误行为：`compiled_properties` 能读到该属性，但候选规格、`dependencies`、`diagnostics` 和逐项 `degradations` 都没有记录它，导出仍成功。
- 影响：ShaderGUI、脚本或手写 HLSL 使用的外部属性可从 SG Blackboard 消失，材质接口与效果发生变化。
- 最小修复方向：对账全部 ShaderLab 属性与 ASE Property 节点；无节点属性在确认外部消费前一律阻断，并记录属性名、原因和影响。
- 关联优化任务：AA-OPT-003。

### [P1] AA-CONTRACT-004 — 恢复可独立通过 Schema 的裸规格 — `src/asecli/cli/export_sg_command.py:41-42,90-95,125-126`

- 证据等级：已验证。
- 触发条件：使用 `--write` 导出有效 ASE Shader，将产物整体交给正式 Draft 2020-12 Schema。
- 错误行为：产物顶层只有 `graph` 和 `report`，Schema 报错 `schema is a required property`。当前 SGCLI 仅因工作树中另有 `spec.load` 解包改动而能预览；机器 Schema 仍只接受内层对象。契约文档第 15–29 行的复合包说明与第 33–45 行的顶层白名单也存在自相矛盾。
- 影响：ASECLI 产物无法被通用 Schema 工具直接验证，并且依赖同时修改 SGCLI，破坏两个 CLI 的独立接口边界。
- 最小修复方向：恢复裸 `sgcli.native.v2` 图规格和独立报告；如确需复合封装，必须另定义新的外层 Schema 和版本，不能将其称为 `sgcli.native.v2` 规格本体。
- 关联优化任务：AA-OPT-004。

### [P2] AA-DATA-005 — 从交付文件中移除随机预览身份 — `src/asecli/cli/export_sg_command.py:67-69,125-126`

- 证据等级：已验证。
- 触发条件：对同一源 Shader、同一目标工程连续导出两次。
- 错误行为：两份内层 `graph` 相同，外层产物 SHA-256 分别为 `3b93228d...` 和 `7540e3e8...`；报告内的瞬态节点 GUID 和 `candidate_sha256` 每次不同。
- 影响：相同输入无法获得可重现产物，产物缓存、diff 和证据对账都会出现噪声。
- 最小修复方向：图规格保持独立稳定；报告只保留稳定的语义证据，或将瞬态 Editor ID 明确放入非确定性运行记录。
- 关联优化任务：AA-OPT-005。

### [P2] AA-RES-006 — 验证资源类型与效果相关导入设置 — `src/asecli/sg_export/sources.py:67-98`

- 证据等级：高置信推断。
- 触发条件：同工程 GUID 解析或 `--asset-map` 返回一个存在的路径，但目标资产类型、sRGB、Normal Map、Wrap、Filter 或压缩设置与源不同。
- 错误行为：当前解析只检查路径前缀、文件存在或 `.meta` 包含 GUID，随后将依赖标记为 `resolved`。
- 影响：资产可成功绑定与编译，但采样结果、法线解码或颜色空间不等价。
- 最小修复方向：通过目标 Editor 只读资产查询核对对象类型和影响 Shader 效果的 importer 设置；无源端证据时标记阻断，不得标记 `resolved`。
- 关联优化任务：AA-OPT-006。
