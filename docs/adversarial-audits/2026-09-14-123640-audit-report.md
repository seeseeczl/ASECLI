## Findings 详情

### [P1] AA-COR-001 — 限制精确模式的材质覆盖组合

- 位置：`/Users/long/GitHub/SGCLI/src/sgcli/native/resources/TargetSettings.cs:18`、`:22`；`TargetEditing.cs` 的 Apply；`target_spec.py:9`。
- URP 位置：当前 tgz 内 `package/Editor/ShaderGraph/Targets/UniversalTarget.cs:1389` 的 `UberSwitchedRenderState`，以及 `BaseShaderGUI.cs:980`。
- 触发：`blend=MultiplySourceAlpha` 且 `options.allowMaterialOverride=true`；也包括先创建精确图，再仅编辑开启覆盖。
- 验证：Python `target_spec.validate` 接受该组合。C# TargetLimits 仅拒绝 zTest Disabled；创建/编辑仅检查 AlphaMode 枚举名字存在，随后无条件应用 allowMaterialOverride。
- 错误机制：开启覆盖后生成器绕过新增的精确 Blend switch，输出 `Blend [_SrcBlend] [_DstBlend]`，没有独立 Alpha 因子。Unlit/Lit SubTarget 把新枚举数值 4 写入材质 `_Blend`，而 BaseShaderGUI 的 BlendMode/switch 仍只处理原有四种值，没有 4 的实现。
- 影响：此合法接口组合无法兑现 `DstColor Zero, One Zero`；材质初始化和后续 Inspector 更新可能产生错误 RGB/Alpha 混合。当前 WaveNoise 样本未开启该选项，所以其已有测试无法覆盖这个问题。
- 最小修复：暂时明确拒绝该组合；创建和编辑必须验证合并后的最终状态，不能只看 patch。若要开放，需同时实现材质枚举、因子属性、初始化、GUI 和生成代码支持。
- 证据边界：本次未用 Editor 新建此组合；不声称已观察具体屏幕像素。
- 关联任务：AA-OPT-001。

### [P1] AA-COR-002 — 恢复普通 Multiply 的未知函数认证保护

- 位置：`/Users/long/GitHub/SGCLI/src/sgcli/native/conversion_gate.py:43`；`surface_guard.py:39` 及 `_alpha_modulate`。
- 本次变化：移除 `fail_unproved=True` 以及未知 Custom Function 的 SEM-BLEND-002 拒绝分支。
- 触发：普通 Transparent/Multiply 的 BaseColor 上游有包含局部变量或多语句的调制函数；生产者错误地将其声明为 verified，report/receipt 与 spec 的 SHA 一致。
- 已验证反例：使用现有 `tests/native/test_conversion_gate.py` 的 `_bundle` 创建隔离测试夹具，仅在临时目录变更夹具。规格通过 `validate_native_spec`，随后 `certify` 返回 `semantic_certified=True`。未改任何生产转换规格。

```hlsl
float3 white = float3(1,1,1);
Out = lerp(white, float3(0.2,0.2,0.2), 0.5);
Alpha = 0.5;
```

函数的两个输出分别接 BaseColor 与 Alpha。目标为普通 Multiply。图输出 RGB=0.6；管线额外执行 `lerp(1,0.6,0.5)` 后为 0.8。假设源只执行图中调制，就产生确定的语义差异。现有正则仅匹配整段单赋值 `Out=lerp(...)`，该反例不匹配，移除兜底后直接通过。

- 为什么属于本次回归：原版认证会以 SEM-BLEND-002 拒绝此函数；新的“非调制函数可认证”测试只测试 `Out=C*2` 的放行，未证明任意未匹配函数均不调制。
- 边界：这不是密码学签名或外部攻击者权限突破。夹具模拟错误生产者报告；哈希无认证密钥，测试名中的 signed 不表示签名。也不声称当前 WaveNoise 精确模式存在重复调制。
- 最小修复：将放宽限制限定于无管线调制的精确模式；普通 Multiply 对无法证明的函数继续失败关闭，或实现可审计的表达式/数据流证明后再允许。不要仅增加这一个字符串的黑名单。
- 关联任务：AA-OPT-002。
