## 试用者安装

安装者必须具备私有仓库权限，并先完成 GitHub CLI 登录：

```bash
gh auth login
mkdir asecli-v0.3.0
cd asecli-v0.3.0
gh release download v0.3.0 --repo seeseeczl/ASECLI
shasum -a 256 -c SHA256SUMS
uv tool install ./asecli-0.3.0-py3-none-any.whl
asecli --version
asecli --help
```
