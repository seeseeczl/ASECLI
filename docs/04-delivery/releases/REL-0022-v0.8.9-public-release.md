# REL-0022 — ASECLI v0.8.9

## 变更集合

- FR/CR/BUG/ADR：AUD-0089（双桥真机等价性验证）。
- 版本/提交/PR：v0.8.9，main 直接提交，新 annotated tag。
- 兼容性说明：修复 0.8.8 中 bridge 后端几何路径不可用的问题；无破坏性变更。

### 缺陷修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| `extract_payload` 白名单缺 `bridge` | 0.8.8 中 `--editor-backend bridge` 的几何读取、节点测量、连线全部失败（`unknown backend 'bridge'`） | 引入 `RAW_PAYLOAD_BACKENDS`，接受 `bridge` / `codely` / `raw` |
| 无标题节点被判非法几何 | 含 ASE 无标题节点（WireNode、继电器，`title_height=0`）的图无法布局 | 只要求 width/height 为正，`title_height` 允许 0 |

第一项是 0.8.8 引入的回归：为避免非法后端名静默落入 MCP 分支而加的白名单，漏掉了 `bridge`。单元测试未覆盖「用真实后端名走几何路径」，因此未被发现。

### 双桥等价性验证（AUD-0089）

对既有真实 ASE 资产，两个后端返回的几何数据 SHA-256 完全一致：

```
Ase_DT_CarModel_v0.3.shader          77155 字节  sha256=3c308ece6adeeba0…
Ase_LiveDesktop_DT_HeadLightAlpha.shader            资源名一致
```

探针 v11 / Codely port 65029，两后端在同一失败点（资源未导入、图未加载、布局算法错误）报同一错误，属等价性佐证。

### 未修复项

`layout --mode meticulous` 对 `Ase_DT_CarModel_v0.3.shader` 报 `('2135','2136')`。该资产 `validate` 通过，两后端报同一错误，与桥无关，属布局算法对特定图拓扑的处理缺陷，留待单独排查。
