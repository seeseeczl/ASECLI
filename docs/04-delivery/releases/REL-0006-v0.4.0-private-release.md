# REL-0006 — ASECLI v0.4.0 私有正式发布

- FR/CR/BUG/ADR：CR-0006、CR-0016、BUG-0022、ADR-0009、ADR-0017；TASK-0043、REG-0021、REG-0047。
- 版本/提交/PR：`v0.4.0`；发布提交 `bab94f74b908bb157c906c5112b05501900dd190`；直接推送私有仓库，无 PR。
- 兼容性说明：统一公共 Editor 与 canonical Attribute；V1 probe 继续兼容；不批量修改用户 Shader，未知 ASE 字段、provider 和 fallback 文件失败关闭；`v0.3.1` 保留为回滚点。
