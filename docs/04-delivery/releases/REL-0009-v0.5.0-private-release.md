# REL-0009 — ASECLI v0.5.0 私有正式发布

## 变更集合

- 版本：`v0.5.0` minor release；新增公开 CLI 参数、spec 字段和 Editor GUI 能力，`v0.4.2` 保留为不可变回滚点。
- 条件置灰：新增 `EnableIfMzgui(source, operator, value)`，支持 `Less`、`LessEqual`、`Equal`、`NotEqual`、`GreaterEqual`、`Greater`；只通过 `EditorGUI.DisabledScope` 控制可编辑状态，不清空材质值，也不代替 Shader 分支。
- 属性呈现：升级到 `asecli.property-presentation.v2`；中文 Tooltip 必填，GUI 自动追加变量名和 Shader 默认值；HelpBox 是用户可选内容，存在不违规、缺失不阻断，CLI 与 ASE 编辑窗口都可增删。
- Provider：工程已有原生 `MZGUI.MZGUI` 时继续使用并只补 authoring/条件 Drawer；确认缺失时安装同名 fallback。两条路径统一 Foldout/Tooltip/HelpBox/EnableIf 标记，跨工程不改 CustomEditor 名。
- 节点图治理：双扇出或像素长度只进入候选；按模块边界、跨阶段/遮挡和消费者离散度决定直连、Local Var 或混合模式。
- 分发：仅私有 GitHub Release，不上传 PyPI、CLI Hub 或公开包仓；不批量修改用户 Shader、材质或 Editor 工程。

## 发布门禁

- 本地：双 Python/全量测试、回归目录、CI governance、供应链、lock 与 diff 检查。
- 构建：仓库外双构建逐字节一致；wheel 隔离安装、GUI fallback 安装 smoke、包内 Skill/C# 资源检查。
- 远端：候选提交对应 GitHub Actions 的 Python 3.10、Python 3.12、package 三项 job 全绿，并从 package artifact 创建正式资产。
- 资产：wheel、sdist、SPDX、供应链报告、漏洞扫描与 SHA256SUMS 重新下载核对。
- 安装：正式 wheel 安装到本机；CLI 版本、帮助、条件参数与 Skill 安装验证；隔离环境完成 `0.5.0 → 0.4.2 → 0.5.0`。
- Editor 边界：本次不启动 Unity/Tuanjie、不截图；自动与资源级验证不能表述为真实 Inspector 编译或视觉通过。

## Release 资产

发布完成后回填候选提交、CI run、Release URL、六项资产 SHA-256、本机安装和隔离回滚证据。

## 回滚

- 触发条件：Tooltip/HelpBox 契约、provider 唯一性、条件元数据、CI、资产摘要、安装或 Skill 任一门禁失败。
- 步骤：停止分发 `v0.5.0`，下载并校验不可变 `v0.4.2` wheel，执行 `uv tool install --force`。
- 边界：不修改用户 Shader、材质、Editor 工程或历史 Release/tag。
