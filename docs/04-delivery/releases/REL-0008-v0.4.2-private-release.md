# REL-0008 — ASECLI v0.4.2 私有正式发布

## 变更集合

- 版本：`v0.4.2` 补丁版本，修复 v0.4.1 快速路径对抗审计发现的问题；`v0.4.1` 保留为不可变回滚点。
- MCP：恢复公开 `McpClient` 的旧四位置参数顺序；初始化两阶段共用 20 秒 monotonic deadline；真实 `tools/call` 保持 120 秒；慢响应统一输出含阶段/耗时/预算的 `BRIDGE_ERROR`/3。
- 回归目录：识别环境变量、`uv run` 选项和条件 bridge 命令，只聚合测试 selector；当前 `50 parsed / 6 conditional / 0 missed`。
- CI：全量 pytest 不再通过测试子进程隐式重复目录 collect，改为命名明确的显式快速步骤，日志直接显示完整性计数。
- 治理：released 记录禁止残留 pending/待回填证据，修正 REL-0007 候选与最终 CI 事实源。
- 分发：仅私有 GitHub Release，不上传 PyPI、CLI Hub 或公开包仓；不改 C# GUI、Shader、材质或 Editor 资源。

## 验证与风险

- 本地：`268 passed, 3 skipped`；3 项为既有真实 Editor bridge 边界，本补丁未触及对应 C#/视觉行为，因此不启动 Editor、不截图。
- 专项：真实本地停滞 socket、旧四位置参数、整体 deadline、CLI 错误码、parser 完整性与 release governance 均有自动回归。
- 发布门禁：双 Python、回归目录、CI governance、供应链、可复现构建、远端 CI、正式资产 SHA、安装与回滚均须通过。
- 停止条件：旧位置参数语义不一致、`missed>0`、超时变为 `INTERNAL`、CI/资产摘要/安装/回滚任一失败。

## Release 资产

远端 package job 完成后回填 wheel、sdist、SPDX、供应链、漏洞扫描与 `SHA256SUMS`。
