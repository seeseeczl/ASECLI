# REL-0017 — ASECLI v0.8.1

## 变更集合

- matcher-v4 识别原生 `Lerp(white,color,alpha)`，仅在白色与 Surface Alpha 同源可证明时折叠，清理孤立节点与映射。
- RGB/Alpha Pass Blend 分别对账；原始 Wave Noise 的不可表示 Alpha Blend 继续失败关闭且不生成部分 spec。
- 与 SGCLI v0.3.2 的普通 authoring/转换认证分离配套；裸 spec、独立 report/receipt 契约不变。
