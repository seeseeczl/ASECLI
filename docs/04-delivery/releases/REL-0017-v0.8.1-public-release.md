# REL-0017 — ASECLI v0.8.1

## 变更集合

- FR/CR/BUG/ADR：CR-0030、ADR-0022、TASK-0066、REG-0063、AA-OPT-201、AA-OPT-202。
- 版本/提交/PR：`v0.8.1@610a7a34bb3f7574ac0a829d7b6df30fe74a132c`；main 直接提交，新 annotated tag，无 PR，未移动旧 tag。
- 兼容性说明：保持 EditorGraphSpec v3 与 `sgcli.native.v3` 裸规格、方向化 spec/report/receipt 契约；收紧仅作用于透明 Multiply 的语义认证，无法证明的 Custom Function 与 Alpha Blend 失败关闭，不生成部分 spec。

- 与 SGCLI v0.3.3 的普通 authoring/转换认证分离配套；裸 spec、独立 report/receipt 契约不变。
