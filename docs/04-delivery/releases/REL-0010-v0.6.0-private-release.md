# REL-0010 — ASECLI v0.6.0 私有正式发布

## 变更集合

- 版本：`v0.6.0` minor release；新增公开 `layout --mode meticulous` 与 `asecli.graph-layout.v2`，`v0.5.0` 保留为不可变回滚点。
- 布局：以 Master/Output 为根从右向左递归展开上游，按 `in_port` 排列完整子树并让父节点输入端口组与子树带居中。
- DAG：共享来源只选择一个主父级；次级边用于穿越、交叉和长度审计，不复制节点、不改 Wire。
- Editor 几何：单次读取真实节点、标题和端口；把缩放窗口坐标还原为图坐标，忽略无连接休眠多 Pass Master，带连接节点缺失几何时失败关闭。
- Local Var / Comment：Register/Get 固定就近距离，Comment 自内向外收框并治理空白、越界、重叠和标题区穿线。
- 安全：`--audit` 只读；`--write` 在硬门禁通过后一次性更新坐标、Comment bounds 与 CHKSM，并保留 `.bak`；Shader 语义指纹必须不变。
- 分发：仅私有 GitHub Release，不上传 PyPI、CLI Hub 或公开包仓，不修改用户生产 Shader。

## 发布门禁

- 本地：Python 3.10/3.12 各 `294 passed, 3 skipped`；回归目录 `52 parsed / 6 conditional / 0 missed`；CI governance、供应链、lock 与 diff 检查通过。
- 构建：固定 epoch 的仓库外双构建逐字节一致；wheel `dbd71e8…c6138a`、sdist `f810778…371499`；隔离 wheel 返回 `asecli 0.6.0`，layout help、parse 与 bundled Skill 安装/幂等 smoke 通过。
- 远端：候选提交对应 GitHub Actions 的 Python 3.10、Python 3.12、package 三项 job 全绿，并从 package artifact 创建正式资产。
- 资产：wheel、sdist、SPDX、供应链报告、漏洞扫描与 SHA256SUMS 重新下载核对。
- 安装：正式 wheel 安装到本机；CLI 版本、layout help 与 Skill 安装验证；隔离环境完成 `0.6.0 → 0.5.0 → 0.6.0`。
- Editor：团结 2022.3.62t13 + ASE 1.9.6.2 已在真实 83 节点/44 Wire Shader 完成只读 V2 审计；发布阶段不重复启动 Editor 或截图。
