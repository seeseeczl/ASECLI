# REL-0010 — ASECLI v0.6.0 私有正式发布

## 变更集合

- 版本：`v0.6.0` minor release；新增公开 `layout --mode meticulous` 与 `asecli.graph-layout.v2`，`v0.5.0` 保留为不可变回滚点。
- 布局：以 Master/Output 为根从右向左递归展开上游，按 `in_port` 排列完整子树并让父节点输入端口组与子树带居中。
- DAG：共享来源只选择一个主父级；次级边用于穿越、交叉和长度审计，不复制节点、不改 Wire。
- Editor 几何：单次读取真实节点、标题和端口；把缩放窗口坐标还原为图坐标，忽略无连接休眠多 Pass Master，带连接节点缺失几何时失败关闭。
- Local Var / Comment：Register/Get 固定就近距离，Comment 自内向外收框并治理空白、越界、重叠和标题区穿线。
- 安全：`--audit` 只读；`--write` 在硬门禁通过后一次性更新坐标、Comment bounds 与 CHKSM，并保留 `.bak`；Shader 语义指纹必须不变。
- 分发：仅私有 GitHub Release，不上传 PyPI、CLI Hub 或公开包仓，不修改用户生产 Shader。
