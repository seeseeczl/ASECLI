## 试用者安装

安装者需先获得私有仓库权限，并完成 GitHub CLI 登录：

```bash
gh auth login
mkdir asecli-v0.2.0
cd asecli-v0.2.0
gh release download v0.2.0 --repo seeseeczl/ASECLI
shasum -a 256 -c SHA256SUMS
uv tool install ./asecli-0.2.0-py3-none-any.whl
asecli --help
```

## 回滚

- 触发条件：Release 资产 hash、包版本、安装 smoke、供应链或既有命令兼容任一失败。
- 步骤：停止分发并强制重装已校验的 v0.1.0 wheel；不删除 Release 历史、不改用户 Shader 或团结工程。
- 验证：确认包版本回到 `0.1.0`、`asecli parse` 成功，并重新核对 v0.1.0 wheel SHA-256。
正式发布前，在临时 CPython 3.12 环境中先安装正式 `v0.1.0` wheel（SHA-256 `8d19a0abe2f9083acaac6a3c1801cc5da38ba2c6a0aa64136d352667ec202318`），随后执行：

1. 安装 `v0.1.0` wheel，包版本为 `0.1.0`，`asecli parse tests/fixtures/step-antialiasing.function.txt` 成功。
2. 强制重装本次 `0.2.0` wheel，包版本为 `0.2.0`，重复 parse 成功，`--help` 列出 15 个子命令。
3. 强制重装 `v0.1.0` wheel，包版本回到 `0.1.0`，重复 parse 成功。

该演练只在临时环境发生，不写入用户团结工程，也不改动任何用户 Shader。
