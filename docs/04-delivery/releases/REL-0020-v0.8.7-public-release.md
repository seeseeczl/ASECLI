# REL-0020 — ASECLI v0.8.7

## 变更集合

- FR/CR/BUG/ADR：AUD-0087（红队循环审计，四轮）。
- 版本/提交/PR：v0.8.7，main 直接提交，新 annotated tag。
- 兼容性说明：新增 Codely Bridge 与 DSH-Bridge 两个编辑器后端，MCP 保留；`--editor-backend` 默认值由 `mcp` 改为 `auto`（按 DSH-Bridge → Codely → MCP 顺序选择）。既有 C# 片段零改造复用。

### 新增能力

- **Codely Bridge 后端**（`cn.tuanjie.codely.bridge`）：TCP 8 字节大端长度帧 + JSON，执行 `execute_csharp_script`。
- **DSH-Bridge 后端**：文件邮箱 IPC（`Library/DSHBridge/<bootId>/`），执行 `unity.code.execute`。
- 三后端统一经 `run_editor_code` 分派；`auto` 结果带 `transport` 字段。

### 审计与加固

四轮红队审计修复项：

| 轮次 | 问题 | 修复 |
| --- | --- | --- |
| 1 | `create`/`comment-group`/`gui-support` 忽略 `--editor-backend` | 补齐参数传递 |
| 1 | `gui-support` 运行时探针硬编码 MCP | 改走统一入口 |
| 2 | 13 处错误文案硬编码 "MCP" | 去 MCP 化 |
| 2 | `probe()` 未输出 `capability_level` | 补齐字段 |
| 3 | 超时后迟到的成功结果被丢弃 | 加宽限轮询 |
| 3 | Bridge 结果借用 `codely` 解包分支 | 独立 `raw` 语义 |
| 3 | 未知后端名静默落 MCP 分支 | 抛 `ValueError` |

历史轮次（AUD-0086 及之前）的跨工程误投递、socket 泄漏、响应伪造、队列饿死等已在前序审计中修复。

## 回滚

- 触发条件：安装失败或后端选择异常导致既有命令不可用。
- 步骤：`uv tool install --force asecli==0.8.6`；或将 `--editor-backend` 显式指定为 `mcp` 恢复旧行为。
- 验证：0.8.6 仍保留完整 MCP 路径，无需回退工程侧改动。
