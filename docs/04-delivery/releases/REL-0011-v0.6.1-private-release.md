- 兼容性说明：`legacy` 保持不变，`meticulous` 原地升级；默认不移动/新增 WireNode，显式路由才写入；`v0.6.0` 保留为回滚点。

- Comment：已有框、成员、嵌套和颜色保持；自内向外收框并只为可可靠推断的占位标题补齐算法作用。
- Local Var：同一结果被两个及以上不同算法组消费时必须 Register/Get；同组复用次数不限但仍治理交叉、重叠和穿节点。
- 路由：默认不改变 WireNode；只有显式 `--route-wires` 才通过当前 ASE Editor API 移动或新增最少锚点，并验证折叠后的逻辑连接等价。
