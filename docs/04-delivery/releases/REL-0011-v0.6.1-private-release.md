# REL-0011 — ASECLI v0.6.1 私有正式发布

## 变更集合

- 版本：`v0.6.1` patch release；将 `meticulous` 原地升级为递归局部鱼骨，`v0.6.0` 保留为不可变回滚点。
- 布局：每个节点都可成为上游局部主骨；直属来源按真实输出端口右对齐，中位/主要分支与目标输入端口水平，其余完整子树平均分布到上下两侧。
- Comment：已有框、成员、嵌套和颜色保持；自内向外收框并只为可可靠推断的占位标题补齐算法作用。
- Local Var：同一结果被两个及以上不同算法组消费时必须 Register/Get；同组复用次数不限但仍治理交叉、重叠和穿节点。
- 路由：默认不改变 WireNode；只有显式 `--route-wires` 才通过当前 ASE Editor API 移动或新增最少锚点，并验证折叠后的逻辑连接等价。
- 分发：仅私有 GitHub Release，不上传 PyPI、CLI Hub 或公开包仓，不修改用户生产 Shader。

## 发布门禁

- 已有本地功能证据：定向 `70 passed`、全量 `313 passed, 3 skipped`、回归目录 `53 parsed / 6 conditional / 0 missed`、CI governance、lock 与 diff 检查通过。
- 已有 Editor 证据：团结 2022.3.62t13 + ASE 1.9.6.2 对真实 248 节点图完成 V3 只读审计；230 个活动节点的全部布局硬门禁为 0，生产 Shader 哈希不变；正常缩放视觉与新增/移动锚点实机仍保持待签收。
- 候选提交、远端 CI、正式资产摘要、本机安装与隔离回滚证据在发布完成后回填并将状态改为 `released`。

## 回滚

- 触发条件：CI、资产摘要、安装、Skill 或回滚验证任一失败。
- 步骤：停止分发 `v0.6.1`，下载并校验不可变 `v0.6.0` wheel，执行 `uv tool install --force`。
- 边界：不修改用户 Shader、材质、Editor 工程或历史 Release/tag。
