# REL-0021 — ASECLI v0.8.8

## 变更集合

- FR/CR/BUG/ADR：AUD-0088（第 5–8 轮红队审计）。
- 版本/提交/PR：v0.8.8，main 直接提交，新 annotated tag。
- 兼容性说明：修正超时语义与大 payload 限制归属；无破坏性变更。

### 审计修复

| 轮次 | 问题 | 修复 |
| --- | --- | --- |
| 5 | 超时后无法判定请求是否已被处理 | 用 `done/` 标记作侧信道，`execution_state` 细分为 `processed` / `not-processed` |
| 6 | 真机用例注释承诺 `ASECLI_TEST_PROJECT` 却未读取 | 实现该环境变量 |
| 7 | 50000 字符上限归给 MCP，却对 Bridge/Codely 一并生效 | 上限按后端区分，非 MCP 后端不套用 |
| — | 真机用例对编辑器重编译瞬时状态敏感 | 加一次防御性重试 |

### 新增

- `tests/test_bridge_live.py`：4 个 `@pytest.mark.bridge` 真机冒烟用例（离线自动跳过）。

### 探针升级兼容

DSH-Bridge 探针由 v8 升至 v11，本轮验证协议与响应字段向后兼容；v11 新增 `referenceBuildMs` / `referenceCached` 性能指标，ASECLI 忽略未知字段。

## 验证与风险

- 测试/构建/审计证据：本机 `555 passed / 4 skipped`（含 4 个真机用例）；`check_ci_governance`、`check_document_governance`、`supply_chain_check`、`check_release_candidate --tag v0.8.8` 全部通过；`git diff --check` 干净。
- **真机验证已完成**（本轮补足 0.8.7 的缺口）：编辑器 pid 67166、探针 v11，`bridge` / `codely` / `auto` 三后端均返回 `win=True;field=m_mzguiAttribs`。
- 已知风险与监控：DSH-Bridge 探针仍未实现 `executionState`，ASECLI 以侧信道替代；真机用例依赖本机编辑器，CI 中自动跳过。
- Go / No-Go 决定与负责人：long 授权推送与发布；门禁全部通过且真机已验证，Go。
